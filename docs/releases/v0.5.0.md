# Midnight v0.5.0 — connectors, voice, documents and simpler settings

- **Connectors (MCP):** add any Model Context Protocol server, a program on this computer or a remote service, in Settings → Automation → Connectors. Its tools ask before each use; read-only tools you review can run without asking until the server changes them. Windows' own agent connectors are listed for one-click adding.
- **Midnight for other apps:** turn on *Let other apps use midnight* so Windows agents, Claude Desktop and other MCP clients can search your chosen folders and start tasks that still wait for your approval. *Register with Windows* adds midnight to the Windows on-device agent registry.
- **Voice input:** install Whisper (about 80 MB, once) in Settings → General → Voice input, then dictate into Ask with the microphone button or Ctrl+Shift+Space. Speech is transcribed in English on this computer.
- **Documents:** missions read PDFs page by page, use Windows' on-device OCR for scanned pages and pictures, read PowerPoint slide text, and can write validated PowerPoint decks.
- **Approvals show what changes:** saving over a file previews a line diff, and a submit lists the fields it will send and where they go.
- **Missions:** live token and cost display against the budget, monthly totals, and search across all mission history.
- **Routines** can be exported as files and imported; imports start unreviewed and in Ask me mode.
- **One model for everything:** quick answers, tasks, research and computer use all run on the model you choose. Without a choice, the default is GPT-6.1 Sol.
- **Settings in tabs:** General, Models, Files & memory, Automation, Display and Data, with add-forms that stay closed until you need them.
- **Launcher:** keyboard focus stays inside approvals and questions (a stray Enter can't approve), Windows High Contrast support, code blocks with a language label and copy button, and files or pictures you can drop or paste into Ask. The tray icon is sharp at every display scale.
- **Packaged builds:** Electron fuses and archive integrity checks, and updates install only an installer signed by the same publisher as the running app.
- Midnight is now dark-only and English-only; the light theme and the Indonesian translation are removed.

## Install or update

Download the installer or package for your platform below, or run the commands in the [README](https://github.com/soliluqoy/midnight2#install). Running the installer again updates an existing installation.

Open Midnight with Ctrl+Win on Windows, Cmd+Alt+M on macOS, or Ctrl+Alt+M on Linux, then sign in through Settings → Models.

Local meaning search installs from Files → Manage search (a one-time download of about 850 MB; Python is no longer needed). The index and embeddings stay local; your chat provider receives retrieved excerpts used in tasks. Turn automatic retrieval off in Settings → Files & memory → Give the model relevant context.

Builds are unsigned, so the in-app updater opens this page instead of installing; download the new installer here. Desktop control and on-device OCR are Windows-only. Included packages: Windows x64 installer and ZIP, macOS Apple silicon ZIP, and Linux x64 AppImage.
