# Midnight v0.6.0 — help with the selection, push-to-talk and personal plugins

- **Help with the selection:** select a paragraph (or put the caret in it) and press Ctrl+Alt+Space. A small prompt opens. You type what you want, review the before and after, and apply. Only the selected text and your instruction go to your model. Every edit offers *Undo this edit*, and the tray's *Recent quick edit* reopens the latest one. Styled phrases, fonts, highlights and paragraph properties are kept. Fields, hyperlinks, tables, tracked changes and embedded objects are not rewritten.
- **Charts:** select a native single-series bar or column chart, press the same shortcut and ask *Change this chart to pie*. The chart stays editable, and changing it back restores it. This is tested on WPS Office 12.1.0.28485. Microsoft Word and linked workbooks are not tested yet.
- **Hold to speak:** turn on *Hold to speak instead of typing* in Settings → General → Help with the selection. Then hold Ctrl+Alt+Shift+Space, speak, and release. Local Whisper transcribes up to 30 seconds and your speech stays on this computer. The result goes through the same review, apply and undo steps. Midnight never listens unless you hold the keys.
- **Personal plugins:** in Settings → Changes, describe a change to Charts or Accent colors. Midnight builds it in a sandbox, previews and checks it, and switches to it only when you choose *Use this version*. To go back, use Tray → Restore last good plugins. An *Official proposal* produces a reviewable source change and leaves your own setup alone.
- **Recovery:** a separate recovery helper can set aside damaged plugin caches and keep your profile and receipts, then start Midnight again.
- **Background work stays in bounds:** quick requests, tasks, background routines and builds each have their own limits. Locking the computer, sleep, or the emergency stop pauses or cancels work. Speech and search models unload when idle, sooner on battery.
- **Search:** the existing Gemma embedding model now runs on a cached native backend with verified downloads. A backend change asks for a reindex.

## Install or update

Download the installer or package for your platform below, or run the commands in the [README](https://github.com/soliluqoy/midnight2#install). Running the installer again updates an existing installation.

Open Midnight with Ctrl+Win on Windows, Cmd+Alt+M on macOS, or Ctrl+Alt+M on Linux, then sign in through Settings → Models.

Selection help, charts, hold-to-speak and recovery work only on Windows. Builds are unsigned, so the in-app updater opens this page instead of installing the update; download the new installer here. Included packages: Windows x64 installer and ZIP, macOS Apple silicon ZIP, and Linux x64 AppImage.
