# Midnight v0.4.0 — compact launcher and local AI context

- A smaller home launcher with Ask and Files modes, separate drafts and queries, pinned websites, and recent missions.
- File search in the home input, with setup and indexing controls under Manage search. Attach a result without replacing your task draft.
- Local retrieval of relevant confirmed memories, past task answers, selected files, and reviewed workflows for your chosen chat model. Busy or unavailable embeddings fall back to word matching.
- Relevant web passages selected locally, plus image, PDF-page, and video-frame inspection for vision-capable models. Audio matches identify moments without generating transcripts.
- Context cache invalidation after source changes or deletion, retrieval deadlines, and checks for cancellation, source permissions, and launcher interactions.
- A shorter README covering installation, use, local search, and development.

## Install or update

Download the installer or package for your platform below, or run the commands in the [README](https://github.com/soliluqoy/midnight2#install). Running the installer again updates an existing installation.

Open Midnight with Ctrl+Win on Windows, Cmd+Alt+M on macOS, or Ctrl+Alt+M on Linux, then sign in through Settings.

Local meaning search needs Python 3.10–3.13 and the runtime installed through Files → Manage search. The index and embeddings stay local; your selected chat provider receives retrieved excerpts used in tasks. Automatic context retrieval can be disabled in Settings → Local file search → Relevant context for AI.

Builds are unsigned. Desktop control is Windows-only. Included packages: Windows x64 installer and ZIP, macOS Apple silicon ZIP, and Linux x64 AppImage.
